# 🟢 Matrix Photo to Text Art Converter

Convert any photo into **Matrix-style text art** using green characters on a black background.

This project is a **pure HTML + JavaScript application** — no installation required. Just open the file in a browser and start converting images instantly.

---

## 🚀 Features

- ✅ Upload any image (PNG, JPG, WEBP, etc.)
- ✅ Convert to Matrix-style text art
- ✅ Black background + green character output
- ✅ Customisable character sets (including your name!)
- ✅ Adjustable:
  - Cell size (detail level)
  - Contrast
  - Brightness
  - Gamma
  - Glow effect
  - Output scale
- ✅ Invert mapping option
- ✅ Download result as PNG
- ✅ No dependencies — runs in any modern browser
